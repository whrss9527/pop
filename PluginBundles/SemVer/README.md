# 语义版本

选中 2 到 200 个 SemVer 2.0 版本号，每行一个，离线比较优先级并复制或替换为升序、降序列表。两个版本时直接显示比较关系。相同优先级保持原输入顺序，原始构建信息和重复项都会保留。

仅接受完整的 `主版本.次版本.修订版本`，以及规范允许的预发布和构建标识。`v1.2.3`、缺少段的版本、数字段前导零和版本行首尾空白都视为无效，不会悄悄修正；允许空行、末尾换行和 Windows CRLF 换行。出错只报告物理行号，不回显该行内容。选中文本最多 32000 个 UTF-8 字节。

优先级遵循 SemVer 2.0：数字段按数值比较，任意位数都不会溢出；预发布低于正式版，预发布中的数字标识低于非数字标识；`+` 后的构建信息不影响优先级。输入不会被执行、上传或保存。
