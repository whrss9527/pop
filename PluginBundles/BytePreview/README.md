# 文件字节预览

在访达中选中一个普通文件，查看前 4096 字节的偏移、十六进制和 ASCII，可复制预览。每行 16 字节；ASCII 的可打印范围为 0x20 到 0x7E，其余字节显示为点。空文件明确显示为空，文件超过上限时明确标出后续内容未读取。

只读取选中的本机普通文件，不联网、不修改或执行文件，不把内容写入日志。目录、最后一级符号链接和特殊文件不会读取；文件以只读、不跟随符号链接和非阻塞标志打开，再检查同一个描述符的类型。父目录中的系统符号链接不在此限制内。文件在预览期间仍可能被别的进程修改；大小是打开时的观察值，预览不提供文件快照一致性保证。

使用独立 `plugin.json` 和包内中英文翻译，不新增宿主功能 ID、目录条目或设置。
