# Pop privacy policy

Pop is a free, open-source right-click toolbox for the Mac by whrss9527.

**Pop collects no data.** It has no account, no servers, no analytics, no advertising and no tracking.

- Everything Pop does with the text, images or files you select happens on your Mac.
- Clipboard history, settings and plugins are stored on your Mac.
- Pop connects to the internet only when you choose an action that needs it: a website search opens in your browser, and AI actions send the selected text to the AI service you set up yourself (your own endpoint and API key; the key is kept in your keychain). On macOS 26 AI actions can use Apple's on-device model instead, which doesn't leave your Mac.
- Translation uses Apple's on-device Translation framework.
- The version from GitHub checks GitHub for updates and downloads plugins from GitHub releases. The Mac App Store version does neither.

Questions: https://github.com/whrss9527/pop/issues
