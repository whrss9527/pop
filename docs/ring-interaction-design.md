# 圆盘气泡与交互设计

## Primary goal

长按唤起后，用户能在不同颜色和复杂壁纸上清楚看到各个功能、立即划向目标并松手执行；停下来查看、取消、靠边操作也同样稳定。展开、悬停和确认都有轻巧反馈，动画不增加操作等待时间。

## Phase 0：事实与接口

**How this serves the primary goal:** 确认当前选择、取消和布局约束，使视觉变化保持已有操作结果。

- `Pop/UI/RingMenuView.swift`：`RingViewModel.updateHover(offset:)`、`setHovered(_:)`、`commit(_:)`、`resetSelection()` 已提供语义选择与三态展示。
- `Pop/Core/Geometry.swift`：`slotCenterOffset(_:radius:)`、`slot(at:)`、`sectorDegrees(_:)`、`RingPlacement` 统一处理位置和命中。圆心死区为 38 点，按住拖动不限制最大距离。
- `Pop/App/PopCoordinator.swift`：松开时重新计算方向；点击模式限制外半径；读取中保存具体槽位意图；执行不等待动画。进入“更多”清除旧选择意图。
- `Pop/UI/Overlay.swift`：非激活面板保留原 App 选区；`OverlayPresentation.Phase` 为 entering、shown、leaving；屏幕变化取消菜单。
- `Pop/UI/Motion.swift`：动画时长统一经过 `Motion.seconds(_:)`；不另外建立计时器驱动选择。
- `Pop/UI/Glass.swift`：`glassSurface(_:tint:)` 已处理 macOS 15 模糊材质和 macOS 26 Liquid Glass。
- 允许的 SwiftUI 接口：`.animation(_:value:)`、`.spring(response:dampingFraction:blendDuration:)`、`.scaleEffect`、`.opacity`、`.offset`、`accessibilityReduceMotion`。不需要引入循环 Animator、第三方动画库或全局鼠标监听。

文档：

- [Apple：弹簧动画](https://developer.apple.com/documentation/swiftui/animation/spring(response:dampingfraction:blendduration:))
- [Apple：动画时序与运动](https://developer.apple.com/documentation/swiftui/controlling-the-timing-and-movements-of-your-animations)
- [Apple：减弱动态效果](https://developer.apple.com/documentation/swiftui/environmentvalues/accessibilityreducemotion)

验证：所有新效果使用上述现有状态和公开接口；编译目标保持 macOS 15。

## Phase 1：视觉与状态设计

**How this serves the primary goal:** 让目标、当前状态和取消位置容易辨认，同时控制菜单占用的空间。

### 视觉结构

- 完整圆盘：图标与短名称放在同一块圆角玻璃按钮内，统一前景色和材质。移除大面积整圆底板和横跨多个功能的移动高亮。
- 圆心：独立轻量玻璃圆心，显示当前内容、功能名称或不可用原因；保留方向小点和取消死区。
- 悬停：目标气泡出现强调色边缘和浅色背景，轻微放大；其他功能保持稳定。目标名称同步强调，语义选择立即更新。
- 确认：目标轻微按下，其他功能淡化，菜单随原有退出流程消失。截图、取色仍立即隐藏全部浮窗。
- 靠边和角落：使用同款独立玻璃按钮，向屏幕内排列，不铺整体底罩；保留固定锚点、当前扇区和“更多”入口。悬停与确认反馈保持一致，安全范围包含气泡、名称与放大空间。
- 长名称：单行、有限缩小和截断，圆心同步显示选中名称，完整名称保留在辅助功能标签和原有提示中。按钮可见宽度随相邻中心距离限制。
- 深色：文字与图标使用可读的前景色，强调色用于选区，避免深色背景上的低对比文字。
- 壁纸对比度：功能按钮、圆心与提示使用系统毛玻璃材质，统一叠加 86% 不透明度的中性衬底；图标使用单色符号，不叠加描边。名称与图标共享底板，减少独立胶囊和重复阴影。
- 浮窗使用 `NSVisualEffectView` 的 `behindWindow` 模糊壁纸与其他窗口；嵌入预览使用 `withinWindow` 模糊窗口内的示例背景。
- 不可用、读取中和确认后的其他入口：只降低前景强调程度，保留完整底色，不把整个入口一起变透明。

### 状态与结果

| 情况 | 视觉反馈 | 操作结果 |
| --- | --- | --- |
| 短按右键 | 不显示菜单 | 原 App 的右键菜单 |
| 达到长按阈值 | 气泡短距离展开 | 立即可选，无需等待展开 |
| 展开中快速划动 | 目标立即强调 | 松手按最终方向执行 |
| 从圆心进入一格 | 对应气泡强调 | 更新当前功能 |
| 相邻或跨多个格子 | 旧格恢复，新格强调 | 不排队，不经过中间功能 |
| 跨首尾格 | 圆心方向点走短路径 | 编号与选择不变 |
| 回到圆心 | 清除目标强调 | 默认松手取消 |
| 划出外圈后松手 | 保持当前方向反馈 | 按住模式仍可执行该方向 |
| 点击模式移出外圈 | 清除当前目标 | 圆外不选择 |
| 可用功能确认 | 目标按下，其他淡出 | 立即执行且冻结目标 |
| 未读完内容 | 保留槽位，圆心显示读取中 | 已松手的选择按原流程等待结果 |
| 内容读取完成 | 仅更新可用状态与提示 | 不换位、不改锚点、不重新展开 |
| 功能不适用 | 降低强调，圆心说明原因 | 长按松手按原偏好关闭或保持 |
| 点击不可用功能 | 原因继续可见 | 保持菜单，不执行 |
| 空格子 | 小圆点占位 | 不执行 |
| 插件等待更新 | 保留位置、更新图标与名称 | 不执行，不替换为其他功能 |
| 点击或松手选择“更多” | 原有列表打开 | 清除读取中的旧功能意图 |
| 从“更多”返回 | 同一组位置与编号 | 等待新的指针移动或键盘输入 |
| Esc、点击外部、焦点丢失 | 快速淡出 | 取消，不执行高亮功能 |
| 连续重新唤起 | 新菜单独立展开 | 旧退场菜单不能接收选择 |
| 显示器、安全区域改变 | 当前菜单取消 | 不在拖动过程中重新排布 |
| 截图、取色 | 即刻移除 | 不把菜单拍进图片 |
| 键盘选择 | 与指针相同的目标强调 | 保持现有数字键、方向键、Enter |
| 减弱动态效果 | 仅显隐与颜色变化 | 无位移、缩放、弹跳或错峰 |

### 动画参数

以下为产品设计参数，需用原生预览验证后调整。

| 动作 | 目标 |
| --- | --- |
| 展开 | 约 280ms 的轻弹簧，起点在最终半径的 60% 附近 |
| 错峰 | 每格约 6ms，总延迟不超过 45ms；不能影响命中 |
| 悬停 | 约 180ms；图标轻微放大，按钮与名称位置不变，不移动功能中心 |
| 确认 | 约 140ms；轻压至约 0.92 倍，不追加执行等待 |
| 退出 | 沿用 170ms 的浮窗清理时序 |
| 边缘 | 短距离展开，气泡使用相同的悬停放大和确认反馈 |

验证：检查 4、8、12 格、长英文名称、四边四角、深浅色和减弱动态效果。全部可见内容须位于当前布局包络内。

布局与绘制共用 RingButtonMetrics 的按钮尺寸和 4 点阴影包络；不再为已移除的弧带、端帽或透明窗口边距限制容量。自然半径由按钮四角及方向命中求得，随后按 1/displayScale 的设备像素步长搜索。优先保留全部动作与正常方向；只有真实空间无解才收进“更多”，没有固定四项或固定半径上限。

## Phase 2：实现

**How this serves the primary goal:** 用已有三态展示实现气泡、悬停和确认，使视觉与真实选择一致。

1. 在 `RingMenuView.slotView(_:phase:)` 的既有位置与动画组合上实现独立气泡，按相邻弦长约束标签宽度。
2. 所有位置使用按钮自身的背景高亮；边缘布局按完整气泡及名称的安全范围校验，保留原有方向命中规则。
3. 在 `Motion.swift` 定义圆盘专用悬停与确认参数，避免改变结果卡片和列表的动画。
4. 语义选择继续由 `RingViewModel` 同步更新；减弱动态效果下禁止方向小点的位置插值及图标弹跳。
5. 保留 `.help` 并为气泡提供可读的辅助功能名称；不增加权限、系统设置、网络或硬件依赖。
6. 更新未发布日志及下一稳定版版本号。

验证：不修改 `MouseTrigger`、`PopCoordinator` 或方向命中规则；布局安全尺寸随气泡调整；确认移除的视觉代码没有调用方；代码中的新注释仅解释当前约束。

## Phase 3：原生预览与验证

**How this serves the primary goal:** 直接检查实际 SwiftUI 渲染和原有交互结果，避免只凭参数判断手感。

- 使用独立预览程序复用真实 `RingMenuView`、`RingViewModel`、`RingPlacement`，不启动 `AppController`、不替换已安装的 Pop、不申请辅助功能权限。
- 预览提供完整圆盘、边缘、角落、4/8/12 格、加载、不可用、首尾切换、确认和取消状态。
- 背景在预览窗口内切换纯白、纯黑、彩色和高反差黑白条纹，不修改桌面壁纸；检查深浅两种界面主题下的错配背景。
- 深浅色与减弱动态效果通过预览视图参数切换，不修改系统偏好；正常运行仍读取系统设置。
- 构建 macOS arm64；运行 `RingInteractionTests`、`GeometryTests`、`EventTapTests`、`OverlayComposingTests`、`OverlayRenderProbeTests`。
- 对快速划动和确认冻结补充有业务意义的回归验证；视觉参数不逐项写镜像断言。
- 对比度测试覆盖 27 种背景色、两种界面主题、可用与不可用状态，以及不同强调色的悬停和确认状态；静止文字与图标对比度至少为 4.5。
- 使用原生 UI 工具检查真实预览。记录中央、边缘、深色、12 格和不可用状态的截图；截图仅作为视觉证据，不能替代交互测试。

验证结果记录在本次交付中。发布、安装替换和合并由独立的交付流程处理。

## 像素边缘布局补充

圆盘独立使用 RingScreenBoundary：顶部延伸到屏幕物理边界，保留 Dock 占用，并用 NSScreen 顶部左右可显示区域推导刘海禁区。结果卡片和提示仍遵守原 visibleFrame。

动作 ID 与物理角序分开；布局求解后一次手势内冻结。相同配置在附近重复唤起可复用上次切口，避免角落半像素变化让端点功能互换。单条缓存不保存模型、窗口或用户偏好；配置与屏幕变化失效。

连续 XY 的隔离预览展示真实布局窗口、菜单栏、禁区、直接功能数与 More。实测需检查逐像素移动、恢复正规圆盘、角落十二项操作行程、中心取消标记、小屏 More 返回和加载时位置保持；几何通过不能代替手感验收。
