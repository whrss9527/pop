按住鼠标右键，指针旁边弹出一个圆盘。往要用的功能方向一划，松开，事情就办完了。

普通点一下右键还是系统菜单，只有按住不放才唤起 Pop，游戏、3D 软件里的右键拖动不受影响。

选中什么，它就懂什么
• 选中外文直接翻译，用的是系统自带的离线翻译。
• 算式直接算出结果，单位、颜色直接换算。
• 图片里的文字直接识别；也可以截一块屏幕，识别里面的文字。

一划就好
• 一百多个功能，圆盘上放哪些、放在哪里都由你定，往那一格一划就执行。
• 按数字键 1–9、0 选格子，Esc 关闭。
• 常用的功能可以单独设快捷键，不同的 App 也可以用不同的圆盘。

顺手的小工具
• 剪贴板历史，可以搜索。
• 把文字或图片贴在屏幕上，截图标注，取色，屏幕标尺。
• 大小写转换、JSON 和代码格式化、Base64 和网址编码、时间戳、二维码等等。
• 图片工具：对访达里选中的图片转换格式、改尺寸、裁剪、拼接。
• AI 润色、总结、解释：macOS 26 上可以用系统内置的离线模型，也可以填自己的兼容 OpenAI 的接口和密钥。

自己加功能
• 用网址模板把任何网站的搜索变成一个功能。
• 用几行 JavaScript 处理选中的文字。

用到才装
很多功能是单独的插件，都已经在 App 里，要用时打开，不用了关掉。

数据都在你自己手里
没有账号、没有服务器、不统计、没有广告。剪贴板历史只在这台 Mac 上，API 密钥存在钥匙串里。

需要的权限
• 辅助功能：识别长按右键、读取选中的文字。在「系统设置 → 隐私与安全性 → 辅助功能」里点「+」把 Pop 加进去，Pop 会带你操作。
• 文件夹访问：要处理访达里选中的文件，先允许 Pop 访问一次文件夹（一般选个人文件夹）。
• 屏幕录制：只有截图、取色时才需要，第一次用时会问。
